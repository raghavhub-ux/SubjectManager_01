# Semester — Study Manager

A lightweight, responsive semester planner for keeping syllabus topics, subject progress, and upcoming evaluations in one place. It runs in any modern browser and stores your study space in that browser using local storage.

## Features

- Semester overview with subject count, syllabus progress, and upcoming evaluation totals
- Subject cards with color tags and progress bars
- Topic-by-topic syllabus checklists, including quick add and completion tracking
- Evaluation calendar with dates, types, subject links, and countdowns
- Subject and evaluation management, including progress filters
- Responsive layout and optional dark mode

## Run it

Open `index.html` in a modern browser. No installation or build step is required.

Your data stays in the browser where you use the app. Use the same browser and device to see your saved study space.
